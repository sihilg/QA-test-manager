# Segurança

## Versões suportadas

Enquanto o projeto estiver em desenvolvimento inicial, somente a versão mais recente da branch `main` recebe correções.

## Reportar vulnerabilidades

Não abra uma issue pública com detalhes exploráveis. Use o recurso **Private vulnerability reporting** do GitHub na página Security do repositório.

Inclua, quando possível:

- componente e versão afetados;
- passos mínimos de reprodução com dados fictícios;
- impacto observado;
- mitigação sugerida.

Não inclua palavras-passe, tokens, documentos reais ou dados pessoais.

## Modelo operacional

O QA Test Manager é executado somente em localhost. Isso reduz a superfície de rede, mas não elimina riscos relacionados com uploads, autenticação local, exportações e ficheiros produzidos pela Eva.
